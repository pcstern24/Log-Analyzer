# Overview

Java Security Log Analyzer is a cybersecurity application that parses server log files to analyze authentication activity and identify potentially suspicious behavior. The program tracks login attempts, analyzes activity by IP address and username, and detects potential brute-force attacks. The project demonstrates log analysis, file processing, data structures, and object-oriented design using Java.

## Features
- Parses server log files
- Tracks successful and failed login attempts
- Analyzes failed login attempts by IP address
- Tracks targeted usernames
- Detects potential brute-force attacks
- Generates security alerts based on failed login thresholds
- Identifies suspicious IP addresses
- Generates a summary report of security activity
